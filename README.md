# 格流 LBM · GoBeyond

LBM 求解器产品展示网站，包含程序化 CAD/STL 示例、参数预览、真实 LBM 格点与 IBM 节点、搅拌流场启动回放以及其他物理模块的实际结果。

这是可独立托管的纯静态网站，不依赖 ChatGPT、OpenAI 登录或外部脚本 CDN。Three.js、几何文件、流场记录与图片均随站点提供。三维动画在浏览器中绘制；网站不提交新的求解任务。

## 本地预览

在本目录运行 `python3 -m http.server 8788`，访问 `http://127.0.0.1:8788/`。

## GitHub Pages

仓库 Settings → Pages → Build and deployment：选择 Deploy from a branch，分支 main，目录 /(root)。`.nojekyll` 保证这些文件直接作为静态内容发布。

更新静态文件并推送 main 后，GitHub Pages 会自动发布。几何、脚本与结果均使用相对路径，支持仓库子路径访问。

## 数据说明

包含两套真实 CAD 文件、243 × 250 × 250 的保存网格、218438 个 IBM 节点和 8 组既有模型结果。第三部分默认保留三维槽体上的两个实际速度切片，28 帧从流体静止开始；“搅拌与扩散”使用 81 帧实际浓度体积场、30720 个固定空间采样点和 320 个可选速度箭头。两种展示均自动循环，支持暂停、拖动进度和回到起点。「搅拌与扩散」默认显示同一时刻的速度与示踪剂浓度剖面，可切回三维点云。

三维记录覆盖示踪剂释放后 0–0.898204 s，示踪剂在开机后 60 转释放；这里的释放后 t=0 不代表流体静止。分子扩散系数为 10⁻⁹ m²/s，湍流 Schmidt 数为 0.7。点云按真实相位从旋转网格重采样到槽体固定坐标；颜色表示欧拉场值，不是粒子轨迹。同步剖面穿过槽轴和释放点，由附近保存点做距离加权显示，箭头为附近速度在剖面上的投影。全槽 CV 曲线使用全部 81 个实算帧的原始统计。显示插值和抽样不用于计算混合时间，CV 沿用对应实算帧的全分辨率统计。

速度切片范围为开机后 0–1.347305 s；这是独立的启动补算，不与体积场拼接。速度色标为 0–12+ m/s，上限以上使用饱和色；浓度点云按 C/C∞ 着色，可仅显示偏差超过 5% 的区域，支持半槽和透明度调整。

回放压缩了帧间时间，以界面的物理时间读数为准。循环返回起点不代表物理场周期回归。参数调整仅更新几何预览与导出的参数，不会重算网格或流场。体积数据的来源和校验信息见 `assets/cloud.json`。

第三方 Three.js 许可证见 `assets/vendor/LICENSE.three`。算例来源记录见 `assets/case-provenance.json`。

模型库中已有的 6 组 GIF 在卡片内直接循环播放；2 组静态计算快照保持原始结果。图片在接近视区时加载；若系统启用减少动态效果，则尊重该偏好显示静帧。点击卡片仍可查看模型说明，但播放动图不需要点击。
